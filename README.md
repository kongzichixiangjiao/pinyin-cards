# 一年级拼音 · 从字母到故事

一套从「单字母」到「讲故事」的拼音教具生产线。**全流程本地跑，0 元**，不调用任何付费 API。

双击 `index.html` 就能用（纯离线，不用开服务器）。

| 级别 | 内容 | 状态 |
|---|---|---|
| **L1 单个拼音** | 单韵母 6 · 声母 23 · 复韵母 8 · 特殊韵母 1 · 鼻韵母 9 · 整体认读 16 · 四声调 4 = **67 个**，每个都有配图 + 口诀 | ✅ 已做完 |
| **L2 拼读** | 两拼 42 个（声母+a / +e o / +i / +u）+ 三拼音节 10 个 = **52 个**，每张都有配图 + 例词 + 拼读式 | ✅ 已做完 |

## 二、卡片长什么样

**L1 字母卡**（四层，从上到下）：配图 → 大字母 → 呼读音 → 记忆口诀

```
   🎙️ 听广播          ← 配图，孩子先看图
  ┌──────────┐
  │    b     │        ← 单层 a / 单层 g 的手写体（Chalkboard SE）
  └──────────┘
     bō               ← 呼读音（蓝字）
  听广播 bbb           ← 口诀，和配图对应
```

口诀全部按人教版配图走（b 听广播、p 爬山坡、m 摸摸脸、d 敲大鼓、t 一把伞……），
图和字对得上，孩子看一遍就能把「图 → 音 → 形」串起来。

**想让某张图更好看**：把你的图命名成 `assets/custom/007.png` 丢进 `custom/`，
重跑 `run_all.py` 就会优先用你的图，emoji 只做兜底。

**L2 拼读卡**：配图 → 拼读式 → 例词

```
      👨
  b — à → bà        ← 声母 + 韵母 → 音节，红字看调号
     爸爸妈妈              ← 例词，孩子看图就懂意思
```

练习版（关掉「显示答案」）：只留 **图 + 例词 + 四线格**，让孩子自己把拼音写出来。

**L3 词语卡**：图 + 汉字 + 拼音，跟原来的小纸条一致。

## 三、页面怎么用

| 位置 | 作用 |
|---|---|
| **顶栏级别页签** | 在 L1~L5 之间切，后面数字是该级单元数 |
| **级别总览** | 该级所有组竖着排开，点任意一张卡进单卡 |
| **单组** | 一组的全部卡片 + 「顺序连播」「看合集视频」「打印纸条」（词语组才有打印） |
| **单卡** | 一屏一张大卡，`←/→` 翻页、`空格` 重读、`P` 藏答案、`Esc` 回本组；手机可左右滑 |

顶栏「显示答案」是总开关。关掉之后：
- 字母卡藏掉呼读音和读法，只剩大字母
- 词语卡变成**空白四线格**（练习版）
- 打印出来的纸条也跟着变练习版

### 手机上怎么看

`index.html` 依赖同级目录的 `assets/` 和 `output/video/`，**只把 html 发给手机是打不开的**（图、音、视频全找不到）。
正确姿势：Mac 起局域网服务，手机连同一个 WiFi 扫码打开。

```bash
cd 拼音卡片 && ./serve.sh        # 默认 8000 端口
```

跑完终端会打印两个地址，并生成 `.serve-qr.png` 二维码，手机直接扫：

```
📱 手机（同一 WiFi）打开:  http://192.168.x.x:8000
💻 本机预览:               http://localhost:8000
```

- 手机端发音（点 🔊）、视频（看合集／单卡视频）、左右滑翻页、藏答案、打印都正常
- **别用微信内置浏览器**打开，微信会拦；用系统 Safari / Chrome
- 第一次跑可能弹 macOS 防火墙授权，点「允许」
- `serve.sh` 调的是 `serve.py`（零依赖），比 `python3 -m http.server` 多了 **HTTP Range（206）**，
  iOS 才能正常播 mp4、拖动音频进度

**如果手机打不开（公司/学校 WiFi 常见）**：办公网多半开了客户端隔离，手机和 Mac 互相不通。
两条路：

```bash
./tunnel.sh        # ① 走公网隧道，手机用 4G 也能开，最省事
```

② 手机开个人热点，Mac 连上热点后再 `./serve.sh`，用新打印的 IP。
（临时地址，Mac 睡眠/断网就失效；链接公网可访问，别外传）

## 五、加内容（唯一要改的地方）

改 `data/curriculum.json`，然后：

```bash
cd build && python3 run_all.py
```

跑一次 = 出卡 + 出音 + 出片 + 重建网页，全量约 **4~5 分钟**（大头是 ffmpeg 编 197 条视频）。

一个单元长这样：

```json
{ "id": 68, "text": "ba", "pinyin": "bā", "say": "八", "tip": "b 和 a 拼一起" }
```

- `id` **全局唯一且递增**，决定文件命名和排序；现在按级分段：L1 = 1~67、L2 = 68~119、L3 = 200~258，L4/L5 留 300+/400+
- `text` 是卡片上的大字（字母 / 汉字 / 句子）
- `pinyin` 是卡下方的读音
- `say` 是**喂给 TTS 的汉字**，不填就用 `text`
  - 例：声母 `b` 的 `say` 填「玻」，TTS 才会读出 bō 而不是字母 b
  - 例：韵母 `eng` 没有常用汉字，填「鞥」代读
- `emoji` 决定卡片上方那张图（字母卡也用它），`tip` 是卡片下方的口诀
- 没有合适的 emoji 就填 `""`，会出一张「待配图」占位，再用 `assets/custom/` 覆盖

### 想加 L2 / L4 / L5

往对应级别的 `groups` 里加组就行，`kind` 决定卡片长相：

| kind | 长什么样 | 用在哪 |
|---|---|---|
| `letter` | 配图 + 大字母 + 呼读音 + 口诀 | L1 |
| `blend` | 配图 + 拼读式（b—à→bà）+ 例词 | L2 |
| `word` | 图 + 汉字 + 拼音（空白版是四线格） | L3 |
| `sentence` | 拼音行 + 汉字行，可带一张图 | L4 |
| `story` | 同 sentence，右下角带页码 | L5 |

```json
{ "id": "L4-1", "name": "第一课", "kind": "sentence", "items": [
  { "id": 201, "text": "我爱我的家", "pinyin": "wǒ ài wǒ de jiā", "emoji": "🏠" }
] }
```

L2 的拼读卡建议这样填（照 L1 的 letter 样式走）：

```json
{ "id": 68, "text": "b—a → ba", "pinyin": "bā", "say": "八", "tip": "声母轻，韵母重，两音相连猛一碰" }
```

## 六、出片（四档粒度）

| 档 | 位置 | 内容 | 时长 |
|---|---|---|---|
| **单条** | `output/video/single/007_b.mp4` | 一个单元一条 | 3~5 秒 |
| **每组一条** | `output/video/group/L1-2_声母_合集.mp4` | 单韵母 / 声母 / 复韵母 / 鼻韵母 / 整体认读 / 四声调 / 每组拼读 / 每天词语，各一条 | 30~60 秒 |
| **每级一条** | `output/video/level/L2_拼读_整级合集.mp4` | 整级连读，**组与组之间插章节页**（大标题 + N 个） | L1 2:19 / L2 2:03 / L3 2:14 |
| **全库一条** | `output/video/all/拼音全集_178个.mp4` | 5 级全部连读，一次性跟读 | 约 6 分半 |

网页里对应的入口：
- 级别页顶部 → 「🎬 整级合集」「📺 全库合集」
- 单组页顶部 → 「🎬 看合集视频」
- 单卡页 → 「🎬 单条视频」

## 九、上线（GitHub Pages，永久链接）

先确认 `index.html` 是最新的，再推：

```bash
python3 build/optimize_images.py    # 有新增/改动卡片时必跑
python3 build/build_index.py        # 重建 index.html（含邀请码）
./deploy.sh git@github.com:<你>/<仓库>.git
```

`deploy.sh` 会做三件事：查资源是否齐全（缺图缺音直接拦下）→ 提交 → 推送；
装了 `gh` 且已登录的话，还会顺手把 Pages 打开，并打印站点地址。

不用脚本的手动版：仓库 Settings → Pages → Source 选 **Deploy from a branch** → `main` / `(root)`，1~2 分钟后生效。

> ⚠️ GitHub Pages 免费版**只能用公开仓库**，等于卡片、音频、源码全部公开可搜。
> 邀请码只能挡住"随手转发"，挡不住"顺着仓库翻"。
> 要连源码一起藏，用 **Cloudflare Pages + 私有仓库**（免费），或 GitHub Pro。

改完跑一次 `python3 build/build_index.py`，码就编进 `index.html` 了（纯前端白名单，没有后端）。

两种发法：

| 方式 | 家长要做什么 | 适合 |
|---|---|---|
| 只发 6 位码 | 打开首页 → 输码 → 进 | 群发同一条链接 |
| 发专属链接 `站点/?k=97DSJQ` | 点开直接进 | 一对一发，省事 |

```bash
python3 build/invite_links.py https://<用户名>.github.io/<仓库>/        # 打印 10 条链接
python3 build/invite_links.py https://xxx.github.io/pinyin/ --md       # 输出表格，方便贴群里
```

- 验证一次存在 `localStorage`，之后打开不用再输（换浏览器/清缓存要重输）
- 专属链接里的 `?k=` 会**自动从地址栏抹掉**，家长不会手滑转发错的
- 本地双击 `index.html`（`file://`）不走邀请码，自己用不受影响
- 想把门关掉：`"enabled": false` 后重新 build

**要注意**：这是纯前端的"门"，源码里能看到码，定位是"别让路人随便进"，不是真正的账号体系。

## 十一、图片瘦身（WebP）

`build/optimize_images.py` 把卡片 PNG 压成两档 WebP，原 PNG 全部保留（出片和打印仍然用 PNG）：

| 产物 | 尺寸 | 用途 | 单张 |
|---|---|---|---|
| `assets/cards/thumb/003_card.webp` | 320×320 | 列表格子 | ~5 KB |
| `assets/cards/web/003_card.webp` | 720×720 | 单卡大图 | ~16 KB |
| `assets/cards/003_card.png` | 900×900 | 出片 / 打印 | ~100 KB |

跑法：

```bash
python3 build/optimize_images.py           # 增量，只处理新增/改动
python3 build/optimize_images.py --force   # 全部重压
```

- 会把源图已不存在的残留 webp 清掉（改 id / 删单元之后必备）
- 老浏览器没有 WebP？`<img onerror>` 会自动退回 PNG，不用管
